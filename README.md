## 存储包怎么选：先对存储类型，再对冗余方式

存储包要抵扣成功，前提是包的类型和Bucket里文件实际的存储类型、冗余方式完全一致。所以选包之前，先去控制台确认你的Bucket用的是哪一档。

OSS按访问频率把存储分成标准、低频、归档、冷归档几档，类型越冷，单位存储成本越低，适合读取越少的数据。经常访问的网站图片、App资源放标准；一个月碰不了几次的报表放低频；备份和长期留存的日志放归档或冷归档。

同一档存储还分同城冗余和本地冗余：同城冗余把数据保存在同一地域的多个可用区，可靠性设计更高，价格也高一档；本地冗余便宜一些。预算敏感、对可用性没有极致要求的场景，本地冗余是更常见的选择。

## 四种抵扣方式：额度怎么扣，比包的类型更容易被忽略

同样叫资源包，额度消耗的逻辑分四种，直接决定你买的规格会不会浪费。

**总量恒定型**：存储包、高防基础包、OSS加速器包、向量存储容量包属于这类。每小时有固定额度，没用完的不会攒到下个小时。以10TB规格存储包为例：某小时实际存储9TB，全部抵扣；存储11TB，抵掉10TB，超出的1TB按量付费。所以存储包按预计的存储量上限选规格就行，不必为了偶尔的峰值买超大规格。

**包月周期型**：目前只有下行流量包。每月固定额度，次月1号重置，当月剩余作废。官方给的例子很能说明问题：本月18日买1个月100GB的下行流量包，18日到月底最多抵100GB，次月1日额度重置。同样的钱，月初买能覆盖完整一个月，月中买只覆盖半个月——想买下行流量包，尽量等月初或者按整月规划。

**动态月周期型**：向量写入和检索包。额度按订单生效日的次日重置，一个包同时抵扣向量写入和向量检索扫描两项费用，换算系数是1GB向量写入抵1GB额度、1TB检索扫描抵0.024GB额度。每个地域每月还有20GB免费写入额度，抵扣时先用免费额度，再走资源包。

**总量递减型**：传输加速包、回源流量包和两种请求包。总额度在有效期内用完为止，不按月重置。比如5000万次规格的请求包买1年，1年内总共5000万次抵扣额度。请求量、流量波动大的场景最适合这类：这个月多扣点、下个月少扣点，都从总额度里走，不存在月度作废。

归纳成一句话：存储类按容量选，下行流量包尽量月初买，请求和回源选总量递减型最省心。

## 指定地域专用和中国内地通用，买之前分清楚

除了高防基础包，OSS资源包购买时都要指定地域。指定地域专用的包只能抵扣该地域的费用，比如华北1（青岛）的存储包只管青岛的Bucket；中国内地通用的包可以在内地多个地域之间共享额度。

两种都买的情况下，抵扣有先后顺序：先扣指定地域专用的，额度用完再扣中国内地通用的，还有超出才按量付费。主力业务在单一地域，买专用包更精确；多地域都有Bucket，通用包更省事。

传输加速包的地域划分更细，分四档：通用地域、内地互访（M2M）、内地与非内地互访（M2O/O2M）、非内地之间互访（O2O）。跨境业务的读者下单前先确认访问方和Bucket各自的位置。

还有个小细节：华北3（张家口）目前不支持新建Bucket，但资源包仍然可以抵扣该地域已有Bucket的费用。

## 资源包和预留空间有什么区别？

覆盖范围不同。资源包覆盖全部存储类型的存储费，加上流量、请求、高防、加速器、向量这些费用；预留空间只对应标准-本地冗余存储这一种容量。你的用量除了存储还有流量和请求的话，预留空间根本覆盖不了。

两者还有一条硬性互斥：已经购买了某个地域的预留空间，就不能再买中国内地通用或同地域的标准-本地冗余存储包。其他类型的资源包不受影响。

选择上可以这样判断：存储类型只有标准-本地冗余一种、容量长期稳定，可以把预留空间和标准-本地冗余存储包放在一起比价；存储类型不止一种，或者还要抵扣流量、请求费用，资源包是唯一能全覆盖的方案。

## 下单前确认这几条抵扣限制

官方帮助文档里写了几条硬性规则，购买页面不会主动提醒，每一条都可能直接影响决定：

1. 只能抵扣当前账号的费用，不支持跨账号转移、过户或共享
2. OSS专用，不能抵扣其他云产品的费用
3. 只抵扣购买之后产生的费用，之前出的账单无法追溯
4. 一种包只抵扣对应的计费项，没有万能包
5. 未用完的额度不退款、不转移，到期作废
6. 额度用完或到期后，超出部分自动转按量付费，服务不中断

## 不同场景的资源包搭配参考

- 网站静态资源、图床、App文件：标准-本地冗余（或同城冗余）存储包 + 下行流量包 + 请求包-标准存储类型
- CDN回源OSS：回源流量包。回源流量费出在OSS这边，CDN自身的流量计费是另一笔账，别搞混
- 备份、日志、合规归档：归档或冷归档存储包，请求走请求包-非标准存储类型
- 跨境、跨地域访问加速：传输加速包，按访问路径选地域类型
- ECS快照：标准-本地冗余存储包可以一起抵扣快照存储费
- 向量检索场景：向量存储容量包 + 向量写入和检索包

## 常见问题

### 资源包额度用完了怎么办？

自动转为按量付费，服务不中断，不需要手动操作。

### 买错了资源包能退款吗？

未用完的额度无法退款或转移，官方建议在当前账号继续用到到期。付款前务必核对计费项、存储类型和地域。

### 资源包能抵扣购买之前的账单吗？

不能。资源包只抵扣购买后产生的费用。

### 中国内地通用资源包覆盖哪些地域？

华东1（杭州）、华东2（上海）、华北1（青岛）、华北2（北京）、华北3（张家口）、华北5（呼和浩特）、华北6（乌兰察布）、华南1（深圳）、华南2（河源）、华南3（广州）、西南1（成都）、华中1（武汉）等内地地域。注意OSS加速器包和向量资源包的通用版只覆盖杭州、上海、北京、乌兰察布、深圳五个地域。

### 预留空间和存储包能同时买吗？

已购某地域预留空间后，不能再买中国内地通用或同地域的标准-本地冗余存储包，两者二选一。
